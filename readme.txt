投稿・固定ページ・カスタム投稿の「どこがクリックされているか」を可視化するヒートマップ解析プラグインです。

== Description ==

Kashiwazaki SEO Heatmap は、WordPress の投稿・固定ページ・カスタム投稿の上で
訪問者がどこをクリックし、どこまでスクロールし、どこで迷っているかを、
実際のページの上に色で重ねて表示するプラグインです。

設定画面でチェックを入れた投稿タイプだけを計測するため、
必要なページだけを対象にできます。

= 主な機能 =

* **クリックヒートマップ** — ページの上にクリックの集中している場所を色で重ねて表示します。赤いほどよく押されています。
* **要素ごとの集計** — 単なる座標ではなく「どのリンク・どのボタンが押されたか」を CSS セレクタ単位で数えます。同じ位置にある別のリンクも区別できます。
* **よくクリックされている要素ランキング** — 押された回数と割合を一覧で確認できます。CSV で書き出せます。
* **スクロール到達率** — 10% 刻みで、どこまで読まれたかを棒グラフで表示します。
* **マウスムーブ** — マウスの動きの分布を重ねて表示します（任意）。
* **レイジクリック** — 同じ場所を短時間に連打した箇所を検出します。
* **デッドクリック** — 押しても何も起きなかったクリックを検出します。
* **外部リンクのクリック** — どの外部リンクが押されたかを記録します。
* **絞り込み** — ページ・期間・端末（デスクトップ / タブレット / スマートフォン）で絞り込めます。
* **配色の変更** — ヒートマップの色を複数の配色から選べます。
* **計測のしきい値** — レイジクリック・デッドクリックの判定条件を設定画面で調整できます。

= プライバシーへの配慮 =

* IP アドレスは保存しません（除外判定に使うだけで、データベースには残しません）。
* 訪問者の識別には、ランダムに生成した値だけを使います。個人を特定する情報は扱いません。
* ブラウザの「追跡しない（Do Not Track）」設定を尊重できます。
* ログイン中のユーザーや特定の権限グループを、計測から除外できます。
* 特定の IP アドレスや URL を除外できます。
* サンプリング（何 % の訪問者を計測するか）を設定できます。
* 生データの保持期間を決め、古いものを自動で削除できます。
* データはこのサイトのデータベースの中だけに保存されます。外部のサーバーへは一切送信しません。
* WordPress の「設定 → プライバシー」の「プライバシーポリシーの下書きを提案」に、このプラグインが集める情報の説明を差し込めます。

== Installation ==

1. プラグインのファイルを `/wp-content/plugins/wp-plugin-kashiwazaki-seo-heatmap/` にアップロードします。
2. WordPress の「プラグイン」画面で Kashiwazaki SEO Heatmap を有効化します。
3. 管理画面の左メニュー「Kashiwazaki SEO Heatmap」→「設定」を開きます。
4. 「計測する投稿タイプ」で、計測したい投稿タイプ（投稿・固定ページ・カスタム投稿）にチェックを入れて保存します。
5. そのページを普通に閲覧すると計測が始まります。「ヒートマップ」画面で結果を確認できます。

== Frequently Asked Questions ==

= 計測が始まりません =

次の点を確認してください。

* 「設定」画面の「計測する投稿タイプ」にチェックが入っていますか。
* 「ログイン中のユーザーを計測から除外する」にチェックが入っている場合、管理者としてログインしたまま見ても計測されません。ログアウトして確認してください。
* キャッシュ系プラグインを使っている場合、JavaScript の最適化や遅延読み込みで計測スクリプトが動いていないことがあります。計測スクリプトの除外設定を確認してください。
* 「サンプリング」が 100 未満の場合、一部の訪問者だけが計測されます。

= 計測データは外部に送られますか =

いいえ。データはこの WordPress が使っているデータベースにのみ保存されます。
外部の解析サービスへは送信しません。

= データが増えすぎるのが心配です =

「設定」画面の次の項目で調整できます。

* 「マウスムーブ」の計測を切る（データ量が最も多い項目です）。
* 「サンプリング」を下げる。
* 「生データの保持期間（日）」を短くし、「古い生データを毎日自動で削除する」にチェックを入れる。

= プラグインを削除するとデータはどうなりますか =

「設定」画面の「プラグインを削除したときに計測データと設定も消す」にチェックが入っていれば、
プラグインの削除時にテーブルごと削除します。チェックを外していれば、データは残ります。

= マルチサイトでも使えますか =

使えます。ネットワーク単位で有効化した場合、削除時のデータ消去も各サイトに対して行います。
