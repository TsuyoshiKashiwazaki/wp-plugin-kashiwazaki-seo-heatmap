Kashiwazaki SEO Heatmap マニュアル

WordPress の投稿・固定ページ・カスタム投稿で「どこがクリックされているか」を、実際のページの上に色で重ねて表示するヒートマップ解析プラグインです。

本プラグインは、設定画面でチェックを入れた投稿タイプのページだけを対象に、訪問者のクリック・スクロール・マウスの動きを記録します。記録したデータは、クリックの集中している場所を示すヒートマップ、押された要素のランキング、スクロール到達率、サイト全体のダッシュボードとして管理画面に表示されます。座標だけでなく「どのリンク・どのボタンが押されたか」まで要素ごとに数えるのが特徴で、ページの改善点を具体的に探せます。個人を特定する情報は保存せず、IP アドレスも記録しません。

クリックヒートマップ

ページのどこが押されているかを、実際のページの上に色で重ねて表示します。赤いほどよく押されている場所です。

要素ごとの集計

座標だけでなく「どのリンク・どのボタンが押されたか」を要素ごとに数え、回数順に一覧表示します。CSV で書き出せます。

行動の可視化

スクロール到達率、レイジクリック、デッドクリック、外部リンクのクリックを検出し、つまずきや離脱の箇所を探せます。

SEO / GEO における強み

本プラグインは SEO / GEO 支援を目的とした kashiwazaki シリーズのひとつです。実際に計測できる行動データを通じて、サイト改善の判断材料を提供します。

クリック行動を根拠にした改善

「どの場所がよく押されているか」「どのリンクは押されていないか」を実際のデータで確認できます。勘ではなく、実際のクリックの分布をもとに、リンクやボタンの配置を見直す材料になります。検索順位への影響は検索エンジン側の判断によるため断定はできませんが、クリックされにくい導線に気づけることは、回遊や目的達成の改善に役立ちます。

レイジクリック・デッドクリックの検出

同じ場所を短時間に連打する「レイジクリック」と、押しても何も起きない「デッドクリック」を検出します。これらは、反応しないボタンや期待どおりに動かないリンクがあるサインであることが多く、離脱や直帰につながりかねません。早い段階で気づくための手がかりになります。

フロントで読み込むファイルを 1 本に絞った設計

フロント側で読み込むのは計測用の JavaScript 1 本だけで、実測 92,142 バイト（gzip 圧縮で約 27,300 バイト）です。フロント側で CSS は読み込まず、管理画面用のファイルも一般のページには読み込まれません。アクセスの多いサイトでは、あとで説明する「サンプリング」（何 % の訪問者を計測するか）を下げてデータ量を抑えられます。フロント側で増えるのは、この 1 ファイルの読み込みだけです。

プライバシーに配慮したデータの扱い

IP アドレスは保存しません（除外の判定にのみ使い、データベースには残しません）。訪問者の識別には、ブラウザの Cookie に保存したランダムな文字列だけを使います。通信の都合でまだ届いていない記録は、届くまでの間だけ訪問者のブラウザの保存領域（localStorage）に残して次に開いたページから送り直し、届いたものは消します（届かないまま 7 日を過ぎたものは送らずに消します）。ブラウザに保存できないときだけ、その記録の番号（ランダムな文字列）と操作の件数を Cookie に最長 7 日残します。ブラウザの「追跡しない（Do Not Track）」設定を尊重でき、ログイン中のユーザーや特定の権限グループも計測から除外できます。個人を特定しにくい形で行動データを扱えるため、プライバシーに配慮した運用の助けになります。

動作要件

項目 要件
WordPress6.0 以上
PHP7.4 以上
対応ブラウザChrome / Firefox / Safari / Edge の各最新版
管理画面の権限管理者（設定の変更とヒートマップの閲覧に必要）
必要な機能WordPress の標準機能のみ。外部サービスへの接続は不要です

すぐに使い始めたい場合は、インストール・初期設定ページに進んでください。各画面の細かい使い方は、ヒートマップ画面・ダッシュボード画面・設定画面の各ページで解説しています。

データの集計には少し時間がかかります。計測はページを閲覧した時点で自動的に始まり、クリックやスクロールが一定の間隔でまとめて送信されます。送信された内容は集計され、ヒートマップ画面やダッシュボード画面に反映されます。
